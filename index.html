Automated Conveyor System

A training-project specification for motor and product-flow control covering discrete I/O, operating modes, sequencing, interlocks, counting, and simulated fault response.

01 · Objective

Develop and document a training conveyor with safe Start/Stop, object detection, counting, modes, and simulated fault response.

02 · Process

An operator starts a conveyor; a sensor detects products; the PLC counts items and stops motion when an unsafe condition occurs.

03 · Architecture

Pushbuttons and field contacts → PLC digital inputs → control logic → motor contactor command and status indication.

04 · Inputs

Start, Stop, E-stop healthy, object sensor, overload healthy, Auto/Manual selector, and motor feedback.

05 · Outputs

Conveyor motor command, run lamp, and alarm indication.

06 · Instrumentation

Discrete object sensor, operator pushbuttons, selector switch, overload contact, and motor run feedback.

07 · PLC logic

Planned seal-in, stop priority, timer, rising-edge counter, mode control, fault latch, acknowledgement, and reset conditions.

08 · Control philosophy

Run only when all permissives are healthy; faults remove the motor command; restoration never causes automatic restart.

09 · Interlocks / permissives

E-stop healthy, overload healthy, valid mode, no active fault, and any downstream-ready condition added to the design.

10 · HMI / SCADA

Planned display of mode, motor command/feedback, object count, active fault, blocked reason, and reset control.

11 · Networking

Local PLC I/O for the base project. Any HMI communication protocol must be recorded as Planned or Studied until implemented.

12 · Fault handling

Motor overload simulation, sensor fault, feedback mismatch, E-stop, invalid reset, and loss of a required permissive.

13 · Testing

Start/Stop priority, E-stop, overload, object count, modes, feedback timeout, fault reset, and restart-inhibit tests.

14 · Documentation

I/O list, logic printout, control narrative, schematic, HMI screenshot, test record, and troubleshooting report.
