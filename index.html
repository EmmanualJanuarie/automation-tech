Automated Conveyor System

Motor and product-flow control demonstrating fundamental discrete I/O, operating modes, sequencing, interlocks, counting, and simulated fault response.

Objective & process

Control a conveyor safely from start/stop stations, detect and count objects, support auto/manual operation, and stop predictably under unsafe conditions.

PLC logic

Seal-in circuit, edge counting, timers, mode selection, sequence states, reset conditions, motor overload latch, alarm handling, and output interlocks.

HMI / instrumentation

Start/stop controls, mode, motor state, object count, active fault, reset, and digital object-detection sensor visualization.

Safety & fault tests

E-stop, stop priority, overload trip, sensor stuck-on, mode change, invalid reset, and restart after restored permissives.

Results

Established deterministic control behavior and an evidence-driven test sequence for normal operation and simulated faults.

Lessons learned

Stop commands and unsafe conditions must dominate; alarms need clear reset rules; field feedback should be checked instead of assuming an output operated.

05 / DIAGNOSTIC METHOD

Fault-finding & troubleshooting

Simulated maintenance reports
Evidence-first, safe-state thinking

FF-01

Level transmitter failure

INSTRUMENT
Problem
Tank level freezes at 62%.
Symptoms
Flat trend; bad-quality alarm; raw input unchanged.
Investigation
Made process safe; checked channel diagnostics, simulated loop current, scaling, and terminal continuity.
Root cause
Open-circuit simulated transmitter loop.
Corrective action
Restore loop; retain fallback inhibit.
Test
Inject 4, 12, and 20 mA equivalents.
Result
0%, 50%, and 100% values track correctly; alarm clears after valid delay.
FF-02

Pump will not start

CONTROL
Problem
Start command accepted but pump remains stopped.
Symptoms
Command bit on; run feedback off; permissive summary false.
Investigation
Reviewed E-stop, low level, overload, mode, interlock, output, and feedback in order.
Root cause
Low-low level permissive not met.
Corrective action
Restore valid level; keep dry-run inhibit.
Test
Start above and below permissive threshold.
Result
Pump starts only under valid conditions and displays the blocked reason.
FF-03

Valve will not open

ACTUATOR
Problem
Valve command is on with no open feedback.
Symptoms
Travel timer expires; flow remains zero.
Investigation
Checked permissives, output command, simulated solenoid, feedback switches, and mechanical state.
Root cause
Open-feedback signal forced false.
Corrective action
Restore feedback and reset travel fault.
Test
Full open-close-open travel test.
Result
Feedback follows within timeout; sequence resumes safely.
FF-04

Motor overload

ELECTRICAL
Problem
Conveyor trips under simulated overload.
Symptoms
Motor output drops; overload alarm latches.
Investigation
Isolated command; checked overload contact state, load condition, and reset logic.
Root cause
Overload input opened during run.
Corrective action
Remove fault cause, restore relay, acknowledge and reset.
Test
Trip during run and attempt unsafe restart.
Result
Immediate stop; restart blocked until healthy and reset.
FF-05

High-high tank level

PROCESS
Problem
Tank reaches shutdown threshold.
Symptoms
HH alarm; inlet closes; fill pump stops.
Investigation
Verified independent threshold, valve state, inflow trend, and response timing.
Root cause
Outlet valve simulated closed during filling.
Corrective action
Stop inflow, diagnose outlet, drain under control.
Test
Raise level through H and HH setpoints.
Result
Alarm at H; shutdown action at HH; controlled reset below safe level.
FF-06

PLC communication failure

NETWORK
Problem
Remote device data stops updating.
Symptoms
Watchdog timeout; invalid quality; PLC comm alarm.
Investigation
Checked link state, IP settings, reachability, protocol status, and device diagnostics.
Root cause
Simulated duplicate IP address.
Corrective action
Correct addressing and document allocation.
Test
Restore link; verify watchdog and tag updates.
Result
Communications recover; stale values remain flagged until confirmed valid.
FF-07

SCADA communication failure

SCADA
Problem
SCADA loses PLC data while PLC control continues.
Symptoms
Greyed values; comm banner; commands disabled.
Investigation
Checked server service, OPC connection, endpoint, certificates concept, and network path.
Root cause
Simulated OPC UA endpoint unavailable.
Corrective action
Restore endpoint and session.
Test
Disconnect/reconnect; verify quality and controls.
Result
PLC remains safe locally; HMI only enables commands after valid data returns.
FF-08

Incorrect flow reading

ANALOG
Problem
Displayed flow is consistently 25% high.
Symptoms
Trend offset; totalized value unrealistic.
Investigation
Compared raw counts, 4–20 mA range, engineering scaling, units, and reference values.
Root cause
PLC upper range set to 125 instead of 100 m³/h.
Corrective action
Correct scale under change control.
Test
Three-point simulated calibration.
Result
Displayed flow matches injected reference across range.
FF-09

Industrial network failure

NETWORK
Problem
Multiple control devices become unreachable.
Symptoms
Several alarms share the same timestamp; switch port down.
Investigation
Mapped affected nodes, checked power, physical link, switch LEDs, topology, and common path.
Root cause
Simulated uplink cable disconnected.
Corrective action
Restore secured connection; inspect cable and port.
Test
Verify links, reachability, comm status, and process data.
Result
Nodes recover; common-cause diagnosis avoids unnecessary device changes.
FF-10

Emergency stop activated

SAFETY
Problem
E-stop circuit changes to unsafe state.
Symptoms
Motion outputs de-energize; E-stop alarm; restart inhibited.
Investigation
Confirm personnel safety first; identify active device; inspect only under authorised safe procedure.
Root cause
Simulated operator E-stop activation.
Corrective action
Resolve hazard, release device, restore safety circuit, perform deliberate reset.
Test
Verify outputs remain off until reset and valid restart.
Result
Safe stop has priority; no automatic restart after circuit restoration.

Safety note: These are training scenarios. Real industrial fault-finding must follow site procedures, risk assessments, permit-to-work requirements, isolation/LOTO rules, authorised test methods, and manufacturer documentation.
