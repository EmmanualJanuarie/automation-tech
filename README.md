# Emmanuel — Automation & Controls Portfolio

A lightweight, single-page industrial automation portfolio built with semantic HTML, modern CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the `portfolio` directory with any simple static web server.

## Personalise before publishing

- Replace `[Surname]` in `index.html`.
- Update the email, GitHub, and LinkedIn placeholder links.
- Add project evidence and PDFs under `assets/documents/`.
- Replace `assets/Emmanuel-CV.pdf` with the final CV.
- Set the Open Graph and Twitter image paths to absolute URLs after choosing the final domain.
